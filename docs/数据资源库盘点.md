## 三、对任务线的影响（建议）

1. **B1/B2 不必干等 MCCD**：ARMCD（真实碑帖、含目标书家）+ lushen（量大、字类全）合并入库，manifest v1 格式不变（来源名 = "颜真卿·东方朔画赞" 等），B3/B4/B5 代码零改动切换真迹。
2. **MCCD 到手后**：作主库（四属性标注最全，供 B6/B7 训练），ARMCD/lushen 作为补充来源并列进 manifest——多来源候选反而提升选字多样性。
3. **授权红线不变**：ARMCD/lushen 是 Apache-2.0（宽松），MCCD 是 CC BY-NC-ND（非商业、需申请）；分发安装包时数据来源声明按各来源分别列明。
4. **待办新增**：① 下载 ARMCD（download.py）与 lushen（674M）→ ② 阿砚写转换脚本产出 glyph-manifest-v1 ③ 通知 GPT 把 B1 提示词的输入源从"仅 MCCD"改为"ARMCD+lushen 先行，MCCD 到货合并"。
