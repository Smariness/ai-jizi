## 核对动作清单（每字体 5 分钟）

1. 打开「授权出处」链接，确认授权声明原文与表格一致。
2. **重点确认**：是否允许「软件嵌入/捆绑分发」——本软件要把字体打包进安装包。
3. 在「核对人 / 日期」列填写：颜钰 / YYYY-MM-DD。
4. 授权声明截图存 `fonts/licenses/` 目录留档。
