## GPU 与资源路径

`app/main.js` 在 ready 前无条件调用 `app.disableHardwareAcceleration()` 并追加 `disable-gpu`。开发入口和验收命令也带 `--disable-gpu`；安装后的快捷方式即使没有额外参数也禁 GPU。实际安装版确认硬件加速为 false、禁 GPU 标志为 true，保留原有 sandbox，不加 `--no-sandbox`。

`resources/app.asar` 内包括 `app/`、`layout.js`、十条文本、四字体、324 张字图和 manifest；Sharp 与 libvips 解到 `app.asar.unpacked`。staging 将 manifest 转为相对路径，源目录的 `docs/glyph_manifest.json` 保持原样。包内所有字图均为 256×256、有透明背景和墨迹；四字体原始文件字节保留。

MCCD 接口位置见包内 `docs/data_slots.json`：`glyphs.db`、`glyph_images/`、`encoder.onnx`。已有真实文件时构建脚本可收集根目录数据库 / 模型及 manifest 引用的 `glyph_images/` 图片。本轮仅放字形目录说明，不生成假数据库或模型。B1/B2 后保持 `glyph-manifest-v1`，更新数据说明和占位版验收基线，再完整重打安装包；不手改已发布的 asar，B5 `layout.js` 不必因字图来源改变而修改。

## 复验命令

以下只使用 `output/b8/installed-app`，存在同产品安装、同名快捷方式或不匹配的安装所有权记录时停止，避免覆盖用户安装。

```powershell
pwsh -NoProfile -File scripts/verify_install.ps1 -Action install
node scripts/verify_installed.js
pwsh -NoProfile -File scripts/verify_install.ps1 -Action uninstall
```

`node scripts/verify_installed.js --manual` 启动程序级断网的可见安装版并等待人工 / Computer Use 操作。输入“宁静致远，宁静致远”，点击第一个“静”选江西拙楷，使用系统对话框保存到 `output/b8/installed_export.png`，完成后另一个 PowerShell 中写 `Set-Content output/b8/native_done.flag done`。脚本会检查导出与当前候选，并关闭测试应用。

本机 Wi-Fi 的系统断网复验（会短时中断其他应用联网，结束或失败均还原原状态）：

```powershell
pwsh -NoProfile -File scripts/start_offline_verification.ps1 -InterfaceAlias WLAN
```

该命令准备重连配置并在后台开始验证；查看 `output/b8/system_offline.stdout.log` 与 `system_offline_report.json`。只支持唯一活动 Wi-Fi 接口；其他接入方式由验收人断开后用安装版复核。临时配置名留在系统临时目录并清理，不记录 SSID、密码或无线配置名到交付报告。
