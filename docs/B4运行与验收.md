## 代码与接口

| 文件 | 职责 |
|---|---|
| `app/main.js` | Electron 窗口、受限 IPC、保存对话框与运行时请求拦截 |
| `app/preload.js` | 只暴露 bootstrap、render、candidates、exportPng 四个方法 |
| `app/service.js` | 读取本地 manifest、列举候选、校验请求并调用 B5 |
| `app/index.html` / `styles.css` / `renderer.js` | 正文与样式控件、SVG/cells 选字、候选栏和导出交互 |
| `tests/service.test.js` | 同仓路径、独立替换、缺字、输入边界与真实 PNG 校验 |
| `scripts/verify_b4.js` | Playwright 操作真实 Electron 的全流程复跑 |

界面请求使用共同约定的样式 JSON 字段：

```json
{
  "style": {
    "text": "海内存知己，天涯若比邻",
    "font": "演示夏行楷",
    "direction": "vertical",
    "char_size": 160,
    "char_gap": 24,
    "line_gap": 40,
    "grid": false,
    "margin": 80,
    "line_length": 5
  },
  "selections": { "1": "江西拙楷" },
  "placeholders": false
}
```

基本字段为 `text, font, direction, char_size, char_gap, line_gap, grid, margin`；`line_length`、`selections`、`placeholders` 为 GUI/B5 扩展。`selections` 以去标点后的零起始正文位置索引（换行不占索引）。沿用 B5 的共同字段约定，B3 `ji.py` 当前仍保留已验收的 CLI 参数接口，GUI 不调用 Python 子进程。

服务调用根目录 `layout.js` 的 `layout()` 与 `exportPng()`。点击优先取 SVG 的 `data-index/data-char/data-source`，字身框留白点击用逆 SVG 坐标转换匹配 `cells[].box`；候选切换由 `selections[index]` 返回 B5 重渲染。字形归一化、SVG 拼装、横竖排与 PNG 生成都由 B5 完成。

manifest 的来源名称不硬编码在界面中；按 `chars[字符][来源]` 枚举候选，路径仅由主进程读取。真迹数据沿用 `glyph-manifest-v1`、透明 PNG 约定即可接入，仍需要数据准备阶段提供实际图片。本轮没有接入 MCCD 或候选智能评分。

界面开启 `contextIsolation`、sandbox，关闭 `nodeIntegration`。静态资源及界面字体均为本地文件，字形以 data URI 内嵌；CSP 禁止连接请求，主进程拦截非 file/data/devtools 请求，禁用权限和新窗口。IPC 只接受本窗口及本地页面，界面不能指定任意 manifest/文件路径。

## 固定依赖与离线恢复

Node.js 22.12+。Electron `44.5.1`、sharp `0.35.4`、验收工具 playwright-core `1.63.0` 为精确版本，依赖树在 `package-lock.json`。正常使用 `npm start` 不安装或下载依赖。

新环境首次准备依赖需要联网：

```powershell
npm ci --ignore-scripts --no-audit --no-fund
node node_modules/electron/install.js
```

前者安装锁文件中的 npm 包，后者取得相同版本 Electron 并按 npm 包的 `checksums.json` 校验后解压。若本机已有完整 npm 缓存和 Electron 下载缓存，可使用：

```powershell
npm ci --offline --ignore-scripts --no-audit --no-fund
node node_modules/electron/install.js
```

注意 `npm ci` 会重建 `node_modules`，之后需再次执行 Electron 安装入口来从缓存恢复 `dist/electron.exe`。本机缓存位于 `%LOCALAPPDATA%/electron/Cache/`，已保存 Windows x64 运行包；官方 SHA256 为 `9b382492dcfee91f8f9e92c91f7972550a1b95d2299cac72279dab33a600d7db`。依赖准备与应用运行分开，离线安装包由 B8 后续处理。
